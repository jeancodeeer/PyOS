El navegador de PyKernel

Todo esta escrito en Python y corre dentro de PyKernel, sin sistema operativo debajo.

Las piezas

ArchivoQue hace
/lib/kernel/net.pyEthernet, IP, TCP, DNS: la red
/lib/ssl.pyTLS 1.3 para HTTPS (X25519, ChaCha20-Poly1305, certificados)
/lib/http/client.pyHTTP/1.1, gzip, redirecciones
/lib/browser/html.pyConvierte el HTML en un arbol
/lib/browser/css.pyHojas de estilo, selectores, cascada
/lib/browser/layout.pyColoca cada cosa: lineas, listas, tablas
/lib/imaging/JPEG y GIF (PNG y BMP en pygame)
/lib/desktop/apps/browser.pyLa ventana: pestanas, barra, marcadores

Lo que no hace

  • No ejecuta JavaScript: las paginas que lo necesitan para mostrarse se ven incompletas.
  • Una sola fuente (la de la tarjeta de video, 8x16), ampliada para los titulos grandes.
  • CSS parcial: sin floats reales, posicionamiento ni grid; flex en filas aproximado.
  • JPEG progresivo, WebP y SVG no se muestran.
