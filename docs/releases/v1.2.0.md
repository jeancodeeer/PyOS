## SnakeyOS 1.2.0: now for ARM64 as well

SnakeyOS now comes in two versions:

| File | For |
|---|---|
| **`SnakeyOSx86.iso`** | 64-bit PCs (x86_64), BIOS or UEFI |
| **`SnakeyOSARM64.iso`** | 64-bit ARM machines with UEFI: QEMU `virt`, ARM servers, Raspberry Pi 4/5 with [UEFI firmware](https://github.com/pftf), development boards with UEFI |

Both versions run the same system: the desktop, the apps, the browser, networking and the updates.

### Try the ARM64 version

```bash
# Debian/Ubuntu: sudo apt install qemu-system-arm qemu-efi-aarch64
cp /usr/share/AAVMF/AAVMF_VARS.fd vars.fd
qemu-system-aarch64 -M virt,gic-version=2 -cpu cortex-a72 -m 1024 \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/AAVMF/AAVMF_CODE.fd \
  -drive if=pflash,format=raw,file=vars.fd \
  -device ramfb -device qemu-xhci -device usb-kbd -device usb-tablet \
  -drive file=SnakeyOSARM64.iso,media=cdrom,if=none,id=cd,readonly=on \
  -device virtio-scsi-pci -device scsi-cd,drive=cd -nic user,model=virtio-net-pci
```

### What is new

- **PyKernel on ARM64**:
  - **Boot:** its own UEFI loader (`BOOTAA64.EFI`) loads the kernel wherever there is free RAM, then the kernel builds its own memory map (MMU).
  - **Hardware:** the kernel reads the hardware from ACPI: the GICv2 interrupt controller, PCIe, the PL011 UART and PSCI for power off and restart. It uses the ARM generic timer.
  - **Screen:** the screen comes from UEFI (GOP), so the text console and the desktop draw directly on it.
  - **Input:** USB keyboard, mouse and touch tablets through xHCI.
  - **Network and disks:** virtio, NVMe and AHCI work the same as on PC, because the kernel translates PCI accesses.
  - **Fast code:** the parts that are `@micropython.viper` on PC (fonts, JPEG, sound, ChaCha20, OpenGL) are written in C for ARM64. A test checks that they give exactly the same results.
- **Mouse:** absolute pointers (USB tablets and touch screens) now work on both versions.

### Limits, honestly

- **ARM64 is tested in QEMU, not yet on physical boards.** It needs UEFI firmware with ACPI. Raspberry Pi 4/5 need the community UEFI firmware.
- **ARM64 needs a GICv2 interrupt controller.** QEMU `virt` with `gic-version=2`, Raspberry Pi 4 and many boards have one. GICv3 is not supported yet.
- **PyWin does not run on ARM64.** It runs Windows x86-64 programs, which need an x86 processor.
- **Arduino and other microcontrollers cannot run SnakeyOS.** They have kilobytes of RAM, and SnakeyOS needs about 512 MB.
