## SnakeyOS 1.1.0 — the new name, a new look

PyOS is now **SnakeyOS**: an operating system written in Python, on PyKernel. Boot it and everything you see is a `.py` file.

**Download `snakeyos-1.1.0.iso`** below and run it:

```bash
qemu-system-x86_64 -m 768 -cdrom snakeyos-1.1.0.iso -nic user,model=virtio-net-pci -device AC97
```

A USB stick works too (Rufus in DD mode, balenaEtcher or `dd`).

### What's new

- **New name and logo**: the blue and yellow snake.
- **New look**: minimalist and Mac-like, in Python's colours (strong blue, soft yellow). The top bar and dock are frosted and light. There is a new blue-to-yellow wallpaper and a light minimal one. Windows open with a short zoom.
- **Boots straight to the desktop**, with an animation. On first boot you create your account; after that, you log in.
- **SnakeyOS Update**: the system updates itself from this repository's GitHub releases, like Windows Update. Updates are signed with ECDSA P-256 and checked against the key built into the system. You can roll back to the previous version.
- **Browser**:
  - JavaScript runs (QuickJS, with a DOM), so React and Vue pages work.
  - Better CSS.
  - TLS 1.2 and 1.3 with AES-GCM and P-256.
  - WebP and SVG images.
- **New apps**: Music, Monitor, Disks.
- **Windows**: Windows-style buttons and a snap hub to arrange windows side by side.
- **Faster**: network, memory allocator, CSS and JavaScript. Only the parts of the screen that changed are redrawn, so the cursor stays smooth.

### Hardware

- **64-bit x86 PCs**, from 512 MB of RAM. BIOS/CSM boot is tested in QEMU.
- **UEFI**: the ISO now carries a UEFI GRUB too. This is experimental and untested on real machines.
- **ARM (Raspberry Pi, phones)**: not yet. It needs a port of the kernel.

`snakeyos-1.1.0.iso.sha256` holds the checksum of the ISO.
