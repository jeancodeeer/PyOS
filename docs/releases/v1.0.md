## SnakeyOS 1.0 — the first release

An operating system written in Python, on [PyKernel](https://github.com/jeancodeeer/SnakeyOS/blob/main/PYKERNEL.md): boot it and everything you see is a `.py` file.

**Download `pyos-1.0.iso`** below and run it:

```bash
qemu-system-x86_64 -m 768 -cdrom pyos-1.0.iso -nic user,model=virtio-net-pci -device AC97
```

Then type `desktop`, or `tour()` to watch SnakeyOS show every app by itself. A USB stick works too (Rufus in DD mode, balenaEtcher or `dd`; boot in legacy BIOS / CSM mode).

### What's in it

- **Desktop**: windows, dock, launcher, icons, right-click menus, folders, trash, login.
- **34 apps** written with pygame: web browser, files, terminal, editor, music, paint, games, and Windows-style apps (Notepad, Writer, Spreadsheet, Slides, Solitaire, Calendar, Snipping, Character Map, On-screen Keyboard, Magnifier, Notes, Tasks).
- **OpenGL 1.x** in software, with PyOpenGL's API.
- **PyWin**: Windows x64 `.exe` files run natively — consoles, Win32 windows and menus, threads, DLLs, C++ exceptions, the registry, OpenGL. DOOM runs (`tools/doom.py` builds it from source and fetches the shareware episode; it is not included in the ISO).

`pyos-demo.mp4` is a 9-minute recording of the guided tour, from the boot to DOOM.

### Honest limits

Tested in QEMU, not on many real PCs. MicroPython, not CPython. PyWin runs 64-bit programs only; no DirectX or Windows networking. The browser does not run JavaScript.

`pyos-1.0.iso.sha256` holds the checksum of the ISO.
