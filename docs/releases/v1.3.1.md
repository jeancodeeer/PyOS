# SnakeyOS 1.3.1

- **No C of its own.** The kernel (PyKernel) is Rust; everything above it is Python.
  - The decoders are Python: WebP, MP3, AAC and H.264 (checked against libwebp and ffmpeg).
  - JavaScript runs on an engine written in Python (`pyos/lib/js`): a parser, a compiler from JavaScript to Python, the standard library and a RegExp engine. React 18 and Vue 3 pages work. QuickJS is gone.
  - The only C left is MicroPython itself and its port configuration headers.
- The x86 kernel is smaller: 455 KB (it was 1.29 MB).
- Two ISOs: `SnakeyOSx86.iso` (PCs, BIOS and UEFI) and `SnakeyOSARM64.iso` (ARM64 with UEFI).
- The README banner shows the SnakeyOS name and logo.

Known: video in Python is slower than before; a 360p video does not play at full speed yet.
